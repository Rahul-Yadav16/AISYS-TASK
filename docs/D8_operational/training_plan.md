# Deliverable D8: User & Staff Training Plan

## 1. Objectives & Scope
This training curriculum prepares library personnel, system administrators, and security officers to operate the AISYS RFID Library Management System safely, efficiently, and with zero disruption to existing legacy systems.

---

## 2. Curriculum Matrix by Role

| Module | Target Audience | Duration | Key Learning Objectives | Practical Exercise |
|---|---|---|---|---|
| **TRN-01: OPAC & Discovery** | All Staff, Student Assistants | 1 Hour | Searching catalog via FTS5, navigating virtual bookshelf, checking copy availability. | Conduct title and keyword searches; locate books on virtual shelves. |
| **TRN-02: Circulation & Policy** | Circulation Desk Staff | 2 Hours | Smart card tap-login, check-out, return, renewals, understanding policy blocks (fines, reference items, blocked patrons). | Process check-out and returns; experience policy block rejections and override procedures. |
| **TRN-03: RFID Staff Station** | Cataloguers, Library Technicians | 2 Hours | Validating items before tagging, encoding RFID tags, assigning tags to records, inspecting EAS armed/disarmed status. | Encode new RFID tags for unassigned books; inspect memory block layout. |
| **TRN-04: Handheld Inventory** | Inventory Technicians | 2 Hours | Setting up shelf audits, sweeping handheld wand across shelves, interpreting audio feedback (880Hz beep vs 440Hz pulse), reconciling missing items. | Conduct inventory sweep on Shelf A; locate a planted misplaced book using audio tones. |
| **TRN-05: Security Gate & Response**| Security Officers | 1.5 Hours | Understanding offline EAS bit detection, gate buzzer/strobe alarms, viewing CCTV incident photos, reviewing alert logs. | Simulate unauthorized exit; review CCTV snapshot and security incident email. |
| **TRN-06: Administration & DR** | System Administrators | 3 Hours | Spreadsheet migration wizard, reconciliation reports, hot backups, disaster recovery restore, offline update packages and rollbacks. | Ingest 20k records; review error log; commit and rollback batch; test hot backup restore. |

---

## 3. Evaluation and Certification
Each trainee completes a hands-on practical assessment covering their role's key workflows. Trainees achieving 100% adherence to standard operating procedures are issued operational sign-off.
